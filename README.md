# RIFT//STRIKE

A self-contained browser-based tactical FPS prototype inspired by classic competitive shooters. No build step or third-party runtime dependencies are required.

## Run locally

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Controls

- **W / A / S / D** — move and strafe
- **Mouse** — aim (mouse-look locks automatically on desktop)
- **Left mouse button** — fire; hold for automatic fire
- **R** — reload
- **Shift** — sprint
- **Space** — vault / hop
- **Esc** — pause or resume

Eliminate all five hostiles before they take you down. Your health, armor, ammo, accuracy, and mission time are tracked.
